# base-mini-poa-tr
Base Mini App — Proof of Attendance (POA) example (TR). Deploy + Mint NFT on Base Sepolia.
## Mint via CLI (Base Sepolia)

1) `.env` oluştur (commit ETME):
   PRIVATE_KEY=0xYOUR_TEST_PRIVATE_KEY
   BASE_SEPOLIA_RPC=https://sepolia.base.org

2) Kurulum:
   npm i -D ts-node

3) Mint çalıştır:
   npx ts-node scripts/mint.ts
